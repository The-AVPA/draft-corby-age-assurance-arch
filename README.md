## About this draft

This is an individual submission to the IETF by Iain Corby, Executive Director of the Age Verification Providers Association (AVPA). It is published here by the AVPA to make the work open to review and contribution.

The draft describes an architecture for age assurance on the Internet. It aligns with ISO/IEC 27566-1 and IEEE 2089.1. It has not been adopted by any IETF working group and does not represent IETF consensus. It has not been formally endorsed by AVPA members.
